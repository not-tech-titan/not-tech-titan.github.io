        <section class="section">
            <h2>Project Description</h2>
            <p>
                Tech Titan Engine (TTE) is a game-development project centered on a
                C++ runtime and a separate visual editor. The editor is intended to
                let creators assemble a game, organize its scenes and entities, and
                configure a project visually. Lua scripting provides a way to add
                game behavior, while the runtime is responsible for running the
                project.
            </p>
            <p>
                The project is being developed around a hierarchy of games, scenes,
                spaces, and entities. Spaces can be configured for 2D or 3D work.
                The goal is to make the structure of a project understandable in the
                editor without limiting the project to one dimension or requiring
                every task to happen in the same tool.
            </p>
            <ul class="skills">
                <li>C++ game runtime</li>
                <li>Visual project editor</li>
                <li>2D and 3D spaces</li>
                <li>Lua scripting</li>
                <li>Separate editor and runtime workflow</li>
            </ul>
        </section>

        <section class="section">
            <h2>Innovation Claim</h2>
            <div class="legacy-notice">
                <strong>Working claim:</strong>
                Tech Titan Engine explores a game-development workflow that combines
                a visual project editor, Lua scripting, and a separate C++ runtime,
                so creators can organize and configure a game visually while
                retaining a code-based path for gameplay behavior.
            </div>
            <p>
                This is a design goal for the project, not a claim that every planned
                capability is finished. TTE is in active development, and the editor,
                runtime, and workflow will continue to change as the prototype grows.
            </p>
        </section>

        <section class="section">
            <h2>Design Workflow</h2>
            <p>
                The current design separates project setup from running the game.
                The editor is where the project is organized and configured; the
                runtime runs the saved project.
            </p>
            <div class="sip-workflow" aria-label="Tech Titan Engine design workflow">
                <div class="sip-workflow-step">
                    <strong>1. Organize</strong>
                    <span>Set up scenes, spaces, and entities in the visual editor.</span>
                </div>
                <div class="sip-workflow-step">
                    <strong>2. Configure</strong>
                    <span>Choose 2D or 3D spaces and add project behavior with Lua.</span>
                </div>
                <div class="sip-workflow-step">
                    <strong>3. Run</strong>
                    <span>Use the separate C++ runtime to run the project.</span>
                </div>
            </div>
